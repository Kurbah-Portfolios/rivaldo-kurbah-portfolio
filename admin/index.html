Secure Portfolio Publishing

The public portfolio is read-only. Upload tools unlock only after GitHub confirms that the supplied credential belongs to KurbahTech and has write access to this exact portfolio repository.

Owner Authentication Required

Enter a fine-grained GitHub personal access token restricted to Kurbah-Portfolios/rivaldo-kurbah-portfolio. Recommended repository permission: Contents — Read and write.

  • The token must authenticate as the GitHub account KurbahTech.
  • The token must have write access to this repository; another user's token is rejected.
  • The token is kept only in this tab's JavaScript memory. It is not placed in HTML, localStorage, sessionStorage, cookies, or the repository.
  • Reloading or closing the page clears the authenticated session.

Secure publishing flow

  1. Authenticate above with your restricted KurbahTech token.
  2. The server-side GitHub API identity and repository permissions are checked.
  3. Only after verification do the local-file upload buttons become available.
  4. Each publish operation re-verifies the authenticated session before writing.
  5. The image and managed JSON data are written to main; if metadata publishing fails after an image upload, the uploader attempts to roll the image back.
