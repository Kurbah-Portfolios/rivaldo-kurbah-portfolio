How publishing works

  1. Click the appropriate upload button and choose an image from your computer or phone.
  2. Fill in the certificate or ministry details in the upload modal.
  3. Paste a fine-grained GitHub token restricted to Kurbah-Portfolios/rivaldo-kurbah-portfolio with Contents: Read and write.
  4. Click Upload & Publish. The browser uploads the image and updates the managed JSON data directly on main.
  5. The token is not saved by the page. GitHub Pages refreshes after the repository update.

The uploader verifies that the token belongs to the KurbahTech GitHub account before publishing. Keep the token private and restrict it to this repository only.
